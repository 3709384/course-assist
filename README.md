# Course Assist · 课程环境一键配置

> 选好这学期的课，剩下的交给它：自动体检、下载安装、配置环境变量，并验证真的能用。

计算机专业的每门课都要一套软件环境：Java 课要 JDK + IDEA，数据库课要 MySQL，操作系统课要虚拟机和 Ubuntu……
对初学者来说，最难的从来不是学课程本身，而是**开学第一周把环境装明白**——版本装错、环境变量没配、装完报错不知道错在哪。

**Course Assist** 就是为解决这个问题而生的 Windows 桌面工具：

1. **选课**：从课程目录里选这学期要上的课
2. **体检**：扫描电脑，告诉你每样东西装没装、版本对不对
3. **一键配置**：安装前可选版本（如 JDK 8 / 17 / 21）和安装位置；缺什么自动下载安装、环境变量自动配好（走官方源，不捆绑、不劫持）
4. **验证**：装完真的跑一遍验证命令，绿了才是真能用；红了会指出卡在哪、怎么修

装不上也不怕：开始前有预检（空间、权限、网络），下载有国内镜像加速，失败有可导出的诊断报告，装错了能一键卸载并还原环境变量。

## 课程覆盖

目标是覆盖本科计算机类的全部主干课程与常见选修。课程包是独立的数据文件（见 [`bundles/`](bundles/)），
新增一门课不需要改代码——往仓库里加一个文件即可。完整课程版图见 [`bundles/catalog.yaml`](bundles/catalog.yaml)。

- 编程基础类：C/C++、Java、Python、数据结构、Web 前端……
- 系统核心类：组成原理、操作系统、计算机网络、编译原理、Linux……
- 数据与智能类：数据库系统、人工智能/机器学习、大数据……
- 软件工程类：软件工程实训、Java Web、移动开发、云计算与容器……
- 方向选修类：网络安全、嵌入式、计算机图形学、数学建模……

## 参与共建

这个项目靠社区一起长大：**给你的课程提交一个课程包**是最受欢迎的贡献方式，
格式很简单，看 [`bundles/README.md`](bundles/README.md) 的规范和 [`CONTRIBUTING.md`](CONTRIBUTING.md) 就能上手。

## 项目状态

🚧 **v0.1 已发布首个可运行版本**（Windows 单文件 exe，免安装）：课程目录与课程包加载、环境体检、
按课程一键配置（版本选择、安装位置、环境变量自动配置、安装后验证）、安装前预检、失败诊断报告、
卸载并还原环境变量。全部 21 门课均已配课程包（draft，待实机验证），每门课都提供多版本、
替代软件与可选工具，界面上按勾选安装，不强制全装。
项目方案见 [`docs/PLAN.md`](docs/PLAN.md)：功能规划、技术选型、课程包规范与开发排期。

本地开发：安装 .NET 8 SDK 后，`dotnet build` 构建，`dotnet test` 运行核心库测试。
